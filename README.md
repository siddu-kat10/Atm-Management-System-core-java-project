
# ATM Management System

## 📌 Project Overview

The **ATM Management System** is a console-based Java application developed using Core Java to simulate basic ATM operations. It allows users to securely access their accounts and perform banking transactions through a simple menu-driven interface.

The project demonstrates fundamental Java programming concepts, including Object-Oriented Programming (OOP), conditional statements, loops, methods, exception handling, and user input using the Scanner class.

## 🚀 Features

- **User Authentication:** Validates the user's account number and PIN.
- **Balance Inquiry:** Displays the current account balance.
- **Cash Withdrawal:** Allows users to withdraw money after checking the available balance.
- **Cash Deposit:** Enables users to deposit money into their accounts.
- **Transaction Validation:** Prevents invalid amounts and withdrawals exceeding the available balance.
- **Menu-Driven Interface:** Provides a simple interface to select ATM operations.
- **Exit Option:** Allows users to safely exit the application.

## 🛠️ Technologies Used

- Java (Core Java)
- Object-Oriented Programming (OOP)
- Scanner Class
- Conditional Statements and Loops
- Methods
- Exception Handling

## 🏗️ Concepts Implemented

- **Encapsulation:** Manages account information using classes and methods.
- **Abstraction:** Organizes ATM operations behind simple method calls.
- **Conditional Statements:** Validates PINs, balances, and transaction amounts.
- **Loops:** Repeatedly displays the ATM menu until the user exits.
- **Methods:** Separates deposit, withdrawal, and balance inquiry operations.
- **Input Validation:** Handles invalid user inputs and transaction amounts.

## ▶️ How to Run

1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Open the project in Eclipse, IntelliJ IDEA, or another Java IDE.
4. Compile the Java source file.
5. Run the main class.
6. Enter the account details and PIN if prompted.
7. Select an operation from the ATM menu.

## 💻 Sample Operations

1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit

The application processes the selected operation and displays the corresponding result.

## 🎯 Learning Objectives

This project was developed to strengthen Core Java fundamentals and understand how OOP concepts can be applied to a real-world banking scenario. It provides practical experience in implementing transaction logic, validating user inputs, and organizing code into reusable methods.

## ⚠️ Note

This is an educational project. Unless additional security and database functionality is implemented, account information and transactions may not persist after the program terminates. It is not intended for real banking use.
